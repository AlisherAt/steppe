# Nike теперь в STEPPE — Instagram

Готовый комплект от 26.09.2026:

- `instagram-post.png` — рекламный пост, пропорции около 4:5, создан imagegen.
- `steppe-nike-reels.mp4` — вертикальный Reels 1080×1920, 30 секунд, 30 кадров/с, H.264 + AAC, встроенная оригинальная инструментальная музыка.
- `reels-cover.png` — обложка Reels 1080×1920.
- `captions.md` — тексты для поста, Reels и закреплённого комментария.
- `references/products.json` — выбранные модели и время проверки каталога.
- `image-prompt.md` — точный промпт рекламного поста и способ генерации.
- `render.mjs` — воспроизводимый видеомонтаж.

Ролик: 0–5 с — анонс; 5–10 — Dunk Low Retro; 10–15 — Air Max 95;
15–20 — Air Force 1; 20–25 — Zoom Vomero 5; 25–30 — призыв открыть каталог.
Переходы — наплыв 0,75 с. Карточки неподвижны, приближения нет.
Каждое название читается не менее четырёх секунд без перехода.

Пары взяты из действующего каталога Nike STEPPE. Упоминания конкретных цен,
фиксированного количества предложений, наличия на складе и официального партнёрства
в креативы не включены. Пост — сгенерированная рекламная композиция по референсам;
ролик — монтаж настоящих фотографий с сайта Nike.

Для повторного рендера: `npm ci`, `npx playwright install chromium`, Python с
`imageio-ffmpeg` (либо переменная `FFMPEG_PATH` с путём к ffmpeg), затем
`node marketing/nike-launch-2026-09-26/render.mjs`.
Для одних обложки/контрольных кадров добавьте `--preview`.

Файлы подготовлены к ручной загрузке в Instagram; публикация в аккаунт не выполнялась.
