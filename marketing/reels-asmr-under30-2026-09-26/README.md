# STEPPE — ASMR-каталог до 30 000 ₸

32 секунды · 1080 × 1920 · 30 кадров/с · H.264/AAC. Спокойный монтаж с наплывами по 0,6 секунды. Основные карточки неподвижны, без изменения масштаба. Детали показаны отдельными статичными кадрами из оригинальных фотографий, согласно новому брифу пользователя.

Цены проверены через живой API STEPPE 26.09.2026; полный ответ сохранён в references/products.json.

Товары с NITRO дешевле 30 000 ₸ в проверенной выдаче не найдены, поэтому NITRO в ролик не включён и выбранным моделям не приписывается. Заголовок ролика — «Хорошая пара. До 30 000 ₸»: заявления о независимой проверке подлинности нет. Текущая цена и доступность могут отличаться; дата проверки указана на экране.

## Монтаж

- 0–3 с — подборка трёх пар.
- 3–7,5 с — Star Vital и цена.
- 7,5–9,5 с — отдельный кадр швов, сетки и подошвы Star Vital.
- 9,5–14 с — Harli Hybrid Skins и цена.
- 14–16 с — отдельный кадр деталей Harli.
- 16–20,5 с — Harli Metallic и цена.
- 20,5–22,5 с — отдельный кадр деталей Metallic.
- 22,5–26,5 с — настоящий снимок корзины STEPPE с двумя парами.
- 26,5–32 с — сокращённый предпросмотр списка заказа и приглашение открыть WhatsApp.

## Звук

Оригинальный синтезированный мягкий инструментал, шуршание бумаги, мягкие шаги и лёгкое нажатие. Без сторонних семплов и голосовой дорожки. Foley-эффекты синтезированы для атмосферы, не записаны с конкретных моделей обуви.

## Финал WhatsApp

capture-cart.mjs создаёт изолированную локальную корзину и снимает настоящий интерфейс сайта. Сервер /api/checkout/whatsapp проверен: он формирует wa.me URL с моделями, размерами и ценами. Ответ сохранён в references/checkout-preview.json. Финальная плашка — оформленный сокращённый предпросмотр, не скриншот отправленного сообщения. Пользователь открывает WhatsApp и сам нажимает «Отправить». При создании ролика сообщения не отправлялись, заказы не размещались, платежей не было.

## Файлы

Из корня проекта с установленными зависимостями:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-asmr-under30-2026-09-26/render.mjs --preview
    node marketing/reels-asmr-under30-2026-09-26/render.mjs

Для нового снимка корзины: node marketing/reels-asmr-under30-2026-09-26/capture-cart.mjs. Цены в references/products.json не обновляются этой командой; перед повторной рекламой проверить их снова. FFMPEG_PATH позволяет использовать собственный FFmpeg. Нужны Arial и Georgia. Ролик не опубликован в Instagram.
