# Nike / чёрно-белая классика

Обновлённый Reels по просьбе владельца: больше чёрных и белых кроссовок классического силуэта.
Все четыре SKU проверены в живом каталоге STEPPE перед монтажом; дата и ссылки сохранены
в `references/products.json`. Фотографии оригинальные, цвета и форма обуви не изменены.

- `steppe-nike-classics-reels.mp4`: 30 секунд, 1080×1920, 30 fps, H.264 + AAC.
- `reels-cover.png`: новая чёрно-белая обложка.
- `render.mjs`: исходник монтажа; запуск из корня проекта через Node.js.
- Плавные наплывы 0,75 секунды, без зума. На каждую модель отведено 5 секунд.
- Оригинальная инструментальная дорожка из предыдущей версии, громкость нормализована.

Пары по порядку: Nike Killshot 2 Premium (IR0801-010), Nike LD-1000 (HJ4687-101),
Nike Pacific (HM4771-105), Nike Field General Suede (IF0666-100).
Палитра — чёрный, белый и светлые нейтральные детали, без ярких цветных моделей.
