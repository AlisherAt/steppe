## Выбранные модели

- Puma Velocity NITRO 4, артикул 311140_17: чёрный верх с серебристой полосой и жёлтым акцентом. Контрастная спортивная модель для темы «Твой темп. Твоя Puma».
- Reebok Club C Grounds UK, артикул 100256877: коричневая замша, светлые детали и невысокая подошва. Городской силуэт для темы «Город — твой маршрут».

Модели найдены в живом каталоге https://steppe-gray.vercel.app/ при подготовке. Фото и метаданные источников сохранены в references. Наличие конкретного размера проверяется на сайте; в рекламе цены и скидки не зафиксированы.
