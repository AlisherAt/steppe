# STEPPE — «Какая твоя?»

Новая молодёжная версия ролика с теми же шестью парами, выбранными пользователем. 24 секунды · 1080 × 1920 · 30 кадров/с · H.264/AAC. Продолжительность увеличена по просьбе пользователя, чтобы успевать читать надписи.

## Что изменилось

- Хук «Какая твоя?» с первого кадра и крупный силуэт Magnetic.
- Наклонные карточки, стикеры, контрастная типографика, лаймовые, розовые и фиолетовые акценты.
- Шесть моделей сменяются через плавное наложение кадров (0,32 секунды); каждая карточка сохраняет один масштаб и положение. Приближения, рывки и повороты во время показа удалены.
- Экран «Пауза — и выбирай» с номерами моделей и приглашением назвать фаворита.
- Финал с медленно движущимися лентами товаров, адресом сайта и текстом «Заказываем после оплаты».
- Оригинальный синтезированный garage-инструментал: 120 BPM, 48 долей за 24 секунды, без сторонних семплов. Дорожка продлена на всю длину ролика.

## Сюжет по времени

- 0–3: хук и одна неподвижная фотография Magnetic.
- 3–15: шесть моделей, по 2 секунды на каждую, включая плавное появление 0,32 секунды.
- 15–19,5: неподвижный общий выбор, шесть номеров без мигающей подсветки — 4,5 секунды.
- 19,5–24: приглашение открыть каталог, ссылка и условия заказа — 4,5 секунды.

Использованы те же фотографии из последнего ролика, визуально сверенные с пользовательскими скриншотами. Метаданные исходной проверки — references/products.json. Повторных обещаний актуального наличия нет. Расцветки, конструкция и логотипы не перерисовывались. Это анимационный монтаж оригинальных фото; натурная видеосъёмка, AI-перерисовка обуви и голосовая озвучка не использовались. Цены и проценты скидок в ролике отсутствуют. Предыдущая версия сохранена отдельно.

## Файлы и запуск

- steppe-your-vibe.mp4 — готовый ролик со звуком.
- cover.png — обложка с выбором шести моделей.
- instrumental.wav — отдельная музыкальная дорожка.
- caption.txt — готовая подпись.
- render.mjs — монтаж; references/ — исходники.

Из корня проекта с установленными зависимостями:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-selected-six-remix-2026-09-26/render.mjs --preview
    node marketing/reels-selected-six-remix-2026-09-26/render.mjs

Можно указать FFMPEG_PATH. Нужны шрифты Arial и Impact. Контрольные кадры находятся в artifacts/reels-selected-six-remix-render. Перед экспортом скрипт проверяет совпадение кадров каждой отдельной карточки после появления: масштаб, положение и изображение должны быть неизменны. В Instagram ролик не публиковался.
