# STEPPE — «Шесть пар. Разные настроения»

Новая версия Reels: 20 секунд, 1080 × 1920, 30 кадров/с, MP4 H.264/AAC, BT.709. Шесть различных пар Puma/Reebok, смена общих и крупных планов, движение изображения, типографика, выбор по номерам и переход к сайту. Оригинальная синтезированная электронная музыка, без чужих семплов. Голосовой дорожки нет.

## Файлы

- steppe-six-moods.mp4 — готовое видео.
- cover.png — обложка с шестью парами.
- caption.txt — готовый текст публикации.
- render.mjs — воспроизводимый монтаж и синтез музыки.
- scenes/ — шесть сцен, созданных встроенным imagegen по фотографиям товаров.
- references/ — фото товаров; selected-products.json содержит источники и артикулы.
- PROMPTS.md — использованные промпты.

Сцены с людьми и окружением являются AI-композициями, а не натурной съёмкой. Часы в ролике задают художественный сюжет дня. Силуэты и расцветки основаны на товарах каталога; актуальные фото, размеры и цены следует смотреть на сайте. При публикации укажите использование AI-контента в доступных настройках площадки. Ролик не опубликован; рост охватов не гарантирован.

## Сценарий

0–1,5 с — «Одна пара на все планы?» и три коротких плана.
1,5–13,5 с — шесть моделей: утро, тренировка, кафе, цвет, детали и вечер; по два плана на модель.
13,5–16,5 с — все шесть пар с номерами и выбор зрителя.
16,5–19,75 с — STEPPE, реальный экран сайта, адрес каталога.
19,75–20 с — возврат к первому плану для зацикливания.

## Запуск монтажа

Из корня проекта с установленными зависимостями:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-variety-v2/render.mjs

Флаг --preview создаёт контрольные кадры без MP4. Вместо imageio-ffmpeg можно задать FFMPEG_PATH. Шрифты Arial/Impact системные, исходный рендер выполнен в Windows. Временные кадры и WAV лежат в artifacts/reels-variety-render. Снимок сайта используется из marketing/reels-2026-09/references/catalog.png.
