# Кастинг твоей следующей пары — STEPPE

Готовый Reels: steppe-sneaker-casting.mp4. 18 секунд, 1080 × 1920, 30 кадров/с, H.264 + AAC, BT.709. Обложка — cover.png, текст публикации — caption.txt.

Это рекламный анимационный монтаж товарных фотографий, не натурная видеосъёмка. Использованы только шесть моделей, повторно проверенных через живой каталог STEPPE 26 сентября 2026 года. Фотографии скачаны по imageUrl из ответов API; синтетические изображения кроссовок не используются. Кадрирование, приближение, поворот и смена планов не изменяют конструкцию и расцветку товара. Фотоисточники, артикулы и результаты проверки сохранены в references/catalog-check.json. Наличие размеров меняется, в ролике нет обещания наличия конкретного размера или фиксированной рекламной цены.

## Сюжет

- 0–2 с: кинолента с парами, «Кастинг твоей следующей пары».
- 2–11 с: шесть кандидатов по 1,5 секунды, выход в кадр, сканирование и приближение детали.
- 11–14 с: выбор фаворита из шести пар.
- 14–17,75 с: быстрое переключение моделей и переход на сайт.
- 17,75–18 с: возврат к заставке для зацикливания.

Музыка синтезирована специально для монтажа: оригинальный электронный бит без сторонних семплов. Голосовой дорожки нет. Ролик не опубликован.

## Повторный рендер

В корне проекта, с установленными зависимостями Node.js и Python:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-casting-2026-09-26/render.mjs

Для контрольных кадров добавьте --preview. Можно указать FFMPEG_PATH вместо imageio-ffmpeg. Шрифты Arial и Impact берутся из Windows. Временные кадры и WAV сохраняются в artifacts/reels-casting-render.
