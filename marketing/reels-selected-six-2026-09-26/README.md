# Reels: шесть моделей со скриншотов пользователя

15 секунд · 1080 × 1920 · 30 кадров/с · H.264/AAC.

Использованы только исходные фотографии шести выбранных моделей. Их дизайн, расцветки и логотипы не перерисовывались. Соответствие фотографиям пользователя проверено визуально 26 сентября 2026 года:

- Puma Starla Women's Training Shoes — 377718_03, чёрная с розовым акцентом.
- Puma Softride Enzo 5 Men's Wide Shoes — 311947_01, чёрная.
- Puma Cell Thrill Men's Shoes — 310168_20, белая с тёмной вставкой подошвы.
- Puma Magnetic Men's Shoes — 310783_02, белая/чёрная/красная.
- Reebok Men's Viva Speed Shoes — 100272598, серая.
- Reebok Men's Energen Run 4 Running Shoes — 100209953, белая с красными шнурками.

Актуальные ссылки на изображения получены из живого API STEPPE. Прямой CDN Puma возвращал HTTP 404, поэтому использованы доступные изображения этих же товаров через штатный /_next/image сайта STEPPE (1080 px). Reebok загружены непосредственно по imageUrl. Метаданные сохранены в references/products.json.

Это анимационный монтаж фотографий, а не натурная видеосъёмка. Начальный телефон — графическая иллюстрация каталога. Нет кадров склада, производства и обещаний физического наличия. Цены и проценты скидки со скриншотов не включены, поскольку меняются. Новый запрос пользователя на конкретные Puma/Reebok заменяет предыдущее пожелание к безбрендовой обуви.

## Сюжет

- 0–3,2 с: каталог на графическом телефоне и выбор Starla.
- 3,2–11 с: все шесть моделей последовательно, приближения деталей и короткие переходы.
- 7–11 с: титр «Заказываем после оплаты» и значки оплаты → заказа.
- 11–15 с: все выбранные модели и «Открой каталог».

## Файлы

- selected-six.mp4 — ролик с музыкой и титрами.
- selected-six-clean.mp4 — версия без титров; значки процесса сохранены.
- cover.png — обложка.
- instrumental.wav — оригинальный синтезированный инструментал без сторонних семплов.
- voiceover-ru.txt — текст и тайминг диктора из предыдущего брифа. Голос в видео не включён.
- caption.txt — текст публикации.
- render.mjs — воспроизводимый монтаж, исходные фото в references/.

## Повторный экспорт

Из корня проекта с установленными Node.js-зависимостями:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-selected-six-2026-09-26/render.mjs --preview
    node marketing/reels-selected-six-2026-09-26/render.mjs
    node marketing/reels-selected-six-2026-09-26/render.mjs --clean

FFMPEG_PATH позволяет указать собственный FFmpeg. Шрифт Arial берётся из системы. Промежуточные кадры — artifacts/reels-selected-six-render. В Instagram ролик не публиковался.
