# Иллюстративный Reels: выбор → оплата → заказ

15 секунд · 1080 × 1920 · 30 кадров/с · H.264/AAC · вертикальный формат 9:16.

## Файлы

- order-story.mp4 — монтаж с тремя точными русскими титрами и инструментальной музыкой.
- order-story-clean.mp4 — версия без титров, для дальнейшего оформления; значки процесса сохранены.
- cover.png — обложка с приглашением открыть каталог.
- instrumental.wav — оригинальный синтезированный инструментал, без сторонних семплов.
- voiceover-ru.txt — точный текст пользователя и тайминг для записи диктора. Озвучка в ролик не включена: инструмент генерации естественной речи недоступен.
- scenes/ — четыре оригинальные AI-сцены, созданные встроенным image_gen; PROMPTS.md содержит запросы.
- render.mjs — воспроизводимый монтаж.

Это анимационный монтаж с плавным масштабированием и смещением сгенерированных статичных сцен, не натурная съёмка и не генерация движения людей. Дизайны обуви иллюстративные, без логотипов; они не подтверждают ассортимент или физическое наличие товара. Пользовательский бриф для этой версии заменяет прежнее требование использовать только модели каталога. Каталог на телефоне — иллюстрация без текста, а не действующий интерфейс оплаты STEPPE. Изменения в работу сайта не внесены.

## Монтаж

- 0–3 с: человек рассматривает каталог на телефоне; «Выбирай свою пару».
- 3–4,55 с: выбранная пара и значок подтверждения на экране.
- 4,55–7 с: плавный переход к крупному плану фактуры выбранной пары.
- 7–11 с: карта со знаком подтверждения → стрелка → заказ; «Заказываем после оплаты».
- 11–15 с: общий план пары; «Открой каталог». Верхняя часть кадра свободна для будущего логотипа.

Никаких других читаемых надписей, брендов, складских полок, коробок или производства. Музыка создаётся синтезатором в скрипте. Ролик не опубликован в Instagram.

## Повторный экспорт

В корне проекта с установленными зависимостями:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-order-story-2026-09-26/render.mjs --preview
    node marketing/reels-order-story-2026-09-26/render.mjs
    node marketing/reels-order-story-2026-09-26/render.mjs --clean

Можно задать FFMPEG_PATH. Шрифт Arial берётся из системы. Контрольные кадры сохраняются в игнорируемую папку artifacts/reels-order-story-render.
