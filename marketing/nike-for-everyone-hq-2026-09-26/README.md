# «У каждого — свои Nike»: версия с исходными фотографиями

Исправление качества предыдущего Reels: вместо скриншотов карточек использованы
оригинальные изображения Nike 1728×1728. Все четыре SKU найдены в каталоге STEPPE,
проверены через публичный API и визуально сопоставлены с изображениями пользователя:

- HM9697-100 — Nike Ava X, белые с чёрным.
- IR1847-103 — Jordan Sixty Plus Low, женская белая расцветка с чёрными деталями.
- IB6687-700 — Book 2 «The Phoenix», оранжевая расцветка.
- HF7310-016 — Nike Air Max Dn8 Big Kids, чёрные с зелёным.

Ссылки на оригиналы, размеры файлов и время проверки — `references/products.json`.
Искусственное повышение разрешения и генеративная перерисовка не использовались.

## Результат

- `steppe-nike-for-everyone-hq.mp4`: 1080×1920, 32 секунды, 30 fps, H.264 CRF 16,
  AAC 48 kHz, 192 kbit/s, faststart.
- `reels-cover.png`: обложка с фотографиями высокого разрешения.
- `render.mjs`: воспроизводимый монтаж; запуск из корня проекта.

Сохранены текст, порядок четырёх моделей, оригинальная музыка, наплывы 0,75 с,
