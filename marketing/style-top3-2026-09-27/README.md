# STEPPE: два ролика «Топ-3 по стилю»

Редакционная подборка из действующего каталога, проверенного 27.09.2026. Это выбор по дизайну и сочетаемости с одеждой, не объективный рейтинг качества, продаж или спортивных характеристик.

## Готовые ролики

- `men/steppe-top3.mp4` — для парней, 57 секунд.
- `women/steppe-top3.mp4` — для девушек, 54 секунды.
- В каждой папке: `steppe-top3-music.mp4` без голоса, `cover.png`, `caption.txt`, `subtitles-ru.srt`, сценарий `story.json`, озвучка WAV и данные выбранных товаров `references/products.json`.

Формат: 1080×1920, 30 fps, H.264, AAC 48 kHz. Русская мужская синтезированная озвучка Microsoft Pavel, собственная инструментальная подложка. Плавные переходы по 0,65 секунды, неподвижный масштаб товара, примерно 10 секунд на пару. Сценарий заканчивается вопросом для комментариев и ссылкой на каталог/WhatsApp.

Для девушек: №3 Reebok Club C Grounds UK 100246127 — сдержанное ретро; №2 Nike Zoom Vomero 5 Rose Gold IQ9603-133 — металлические детали и многослойный силуэт; №1 Nike Astrograbber Suede IQ7611-001 — тонкий профиль и чёрно-светлая палитра.

Отобраны взрослые модели с доступными вариантами. Shox IQ0299-010 исключены из мужской подборки из-за остатка лишь небольших размеров; вместо них выбраны AV3595-017 с EU 42, 44 и 45 среди доступных. Коричневые Reebok 100256877 заменены серыми 100246127 с более широким набором женских размеров. Наличие конкретного размера не гарантируется после даты проверки.

## На что опирались

Проверены фотографии, полные артикулы, расцветки, цены и варианты через публичный API STEPPE. Снимки этих данных, время проверки, прямые ссылки на каталог и официальные страницы моделей находятся в `references/products.json` каждого ролика. Использованы клиентские цены сайта с уже начисленной наценкой и округлением. Для каждой выбранной пары цена одинакова у всех доступных вариантов в сохранённом ответе.

При выборе направлений учтены обзоры [Vogue о сочетаниях кроссовок](https://www.vogue.com/article/how-to-style-sneaker-trends) и [Vogue о тонких силуэтах](https://www.vogue.co.uk/article/spring-summer-2026-shoe-trends): лаконичное ретро, замша и металлические акценты. Это ориентир для нашей стилизации; издания не составляли этот топ и не рекомендуют STEPPE.

Названия расцветок и материалы сверялись с [Nike Field General Suede](https://www.nike.com/t/field-general-ref-mens-shoes-MMjfAd3J/IF0666-100), [Nike Astrograbber Suede](https://www.nike.com/t/astrograbber-suede-womens-shoes-8c3U2aoG/IQ7611-001) и [Nike Zoom Vomero 5 Rose Gold](https://www.nike.com/t/zoom-vomero-5-womens-shoes-with-reflective-accents-81TPKW/IQ9603-133). Советы по одежде — редакционные, не обещание одинаковой посадки или комфорта для всех.

Оригинальные продуктовые фотографии сохранены без генеративной замены дизайна, цвета или логотипов. У Field General использован ранее скачанный официальный снимок того же артикула; актуальная цена проверена заново.

## Пересборка

Из корня проекта:

```powershell
node marketing/style-top3-2026-09-27/render.mjs men
node marketing/style-top3-2026-09-27/render.mjs women
```

Нужны зависимости проекта, Chromium для Playwright и FFmpeg (`FFMPEG_PATH` либо Python-пакет `imageio-ffmpeg`). WAV-файлы включены: голос повторно генерировать не требуется. Для изменения речи запустите `voice.ps1` нужной папки в PowerShell 7 с установленным Microsoft Pavel. `--preview` формирует только контрольные кадры и обложку.

Рендер сохраняет временные кадры и аудиомикс в игнорируемый `artifacts/`. Содержимое роликов фиксировано; новые цены из ежедневного обновления каталога автоматически в видео не подставляются. Перед повторной публикацией проверить ссылки и цены.

## Проверка результата

Просмотрены все пять сцен каждого ролика на контактных листах, крупный вступительный кадр и кадр из итогового MP4. Все четыре MP4 полностью декодированы FFmpeg без ошибок. Версия для парней: 1710 кадров / 57 секунд; для девушек: 1620 кадров / 54 секунды. Пиковый уровень звука версий с речью −1,4 dBFS, клиппинга нет. Фотографии Nike — 1728×1728, Reebok — 2000×2000. Обе подписи короче 2200 символов.
