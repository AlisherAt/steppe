# STEPPE — мужской ASMR-каталог до 30 000 ₸

32 секунды · 1080 × 1920 · 30 кадров/с · H.264/AAC. Графитовый фон, стальная вторичная типографика, песочный акцент и крупный рубленый шрифт. Плавные наплывы по 0,6 секунды. Основные карточки неподвижны: без приближений, вращений и резких движений. Детали — отдельные статичные кадры оригинальных фотографий.

## Проверенные модели

Цены проверены через живой API STEPPE 26.09.2026. Ответ сохранён в references/products.json.

- Puma Softride Enzo 5 Men's Wide Shoes, 311947_01 — 28 000 ₸, чёрные.
- Puma Magnetic Men's Shoes, 310783_02 — 27 500 ₸, белые с чёрными и красными деталями.
- Reebok Men's Viva Speed Shoes, 100272598 — 21 000 ₸, серые.

Все три модели относятся к мужским. Использованы оригинальные товарные фотографии: Puma через оптимизатор STEPPE (1920 px), Reebok через исходный CDN магазина. Модели и их материалы не генерировались. Цена и доступность могут измениться; дата указана в ролике. Перед повторной рекламой следует перепроверить каталог.

## Звук и заказ

Оригинальный синтезированный инструментал в более низком регистре, мягкое шуршание бумаги, шаги и нажатие. Без сторонних семплов и озвучки. Эффекты создают атмосферу; это не записи звука конкретных моделей обуви.

capture-cart.mjs создаёт изолированную локальную корзину Enzo + Magnetic (55 500 ₸) и снимает настоящий интерфейс. /api/checkout/whatsapp проверен: формируется ссылка wa.me со списком товаров, размеров и цен. Проверка сохранена в references/checkout-preview.json. Финальный экран — сокращённый оформленный предпросмотр. Сообщения не отправлялись, заказы и платежи не создавались; покупатель самостоятельно отправляет подготовленное сообщение.

## Файлы и воспроизведение монтажа

- steppe-asmr-men-under30.mp4 — готовый Reels.
- cover.png — обложка.
- caption.txt — подпись к публикации.
- instrumental.wav — музыка и эффекты.
- references/ — фотографии, проверенные товары, снимок корзины и подготовленный заказ.
- render.mjs — монтаж; capture-cart.mjs — получение снимка корзины.

Из корня проекта с установленными npm-зависимостями:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-asmr-men-under30-2026-09-26/render.mjs --preview
    node marketing/reels-asmr-men-under30-2026-09-26/render.mjs

Для нового снимка корзины: node marketing/reels-asmr-men-under30-2026-09-26/capture-cart.mjs. Эта команда не обновляет цены в products.json. FFMPEG_PATH позволяет задать собственный FFmpeg. Требуется Arial. Проверка renderer сравнивает кадры каждой основной карточки в разные моменты: масштаб и содержимое должны совпадать. Ролик не опубликован в Instagram.
