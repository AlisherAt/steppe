# STEPPE — подберём ваши Nike

Reels по четырём изображениям, приложенным пользователем. Использованы именно исходные
скриншоты; для видеокадрирования выбраны области с обувью без элементов интерфейса.
Кроссовки не перерисованы, фотографии похожих моделей не подставлялись.
Чёткость товарных фотографий ограничена разрешением исходных скриншотов.

## Готовые файлы

- `steppe-nike-for-everyone.mp4` — 32 секунды, 1080×1920, 30 fps, H.264/AAC.
- `reels-cover.png` — обложка.
- `references/` — четыре исходных изображения и координаты кадрирования.
- `render.mjs` — монтаж и оригинальная инструментальная дорожка; запуск из корня проекта.

Карточки неподвижны; плавные наплывы 0,75 секунды, приближения нет.

10–15 — женские Jordan Sixty Plus Low; 15–20 — баскетбольные Nike Book 2;
