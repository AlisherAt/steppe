# Reels STEPPE — «Спорт или город?»

- Готовый файл: steppe-sport-or-city.mp4, 1080 × 1920, 30 кадров/с, 18 секунд, H.264 + AAC.
- Обложка: cover.png. Текст публикации: caption.txt.
- Монтаж из фотографий реальных товаров и снимка сайта: крупная типографика, движение карточек, шесть сцен. Голоса нет; весь смысл передан надписями.
- Бит синтезирован специально для ролика программно. Сторонние музыкальные записи и семплы не использованы.
- Изображение каталога иллюстрирует интерфейс на момент съёмки. Актуальное наличие и цены проверяются на сайте.
- Ролик подготовлен для публикации, но не опубликован. Охваты и рекомендации Instagram не гарантируются.

## Сценарий

0–3 с: вопрос «Спорт или город?» и две пары.
3–6 с: Puma Velocity NITRO 4, чёрно-жёлтая, 311140_17.
6–9 с: Reebok Club C Grounds UK, коричневая замша, 100256877.
9–12 с: реальный экран каталога STEPPE.
12–15 с: размеры EU, цены в тенге, корзина → WhatsApp.
15–18 с: выбор 1 или 2, приглашение в комментарии и адрес сайта.

## Повторный рендер

Из корня репозитория с установленными Node.js, Python и зависимостями проекта:

    python -m pip install imageio-ffmpeg
    npx playwright install chromium
    node marketing/reels-2026-09/render.mjs

Можно задать FFMPEG_PATH вместо установки imageio-ffmpeg. Для контрольных кадров: добавьте --preview. Шрифты Arial и Impact берутся из системы (исходный рендер — Windows). Временные кадры и WAV находятся в игнорируемой папке artifacts/reels-render.

Для публикации загрузите MP4 как Reels, выберите приложенную обложку, вставьте caption.txt и добавьте ссылку на STEPPE в профиль. Не накладывайте второй музыкальный трек поверх бита без регулировки громкости.
