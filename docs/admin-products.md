# Управление товарами STEPPE

Панель: `/admin`. Доступна только зарегистрированным аккаунтам, которым отдельно
назначена роль администратора. Обычная регистрация эту роль не выдаёт.

## Первый запуск

1. В `.env.local` должны быть действующие настройки SeaTable. В Vercel используются
   те же серверные переменные. Секреты не должны иметь префикс `NEXT_PUBLIC_`.
2. Выполните `npm run seatable:setup`. Команда создаёт недостающие таблицы
   `STEPPE_Admins`, `STEPPE_ManualProducts`, `STEPPE_HiddenProducts`.
3. Зарегистрируйте свой аккаунт на сайте через `/login`.
4. В доверенном терминале проекта выполните `npm run admin:grant -- ваш_логин`.
   Роль привязана к неизменяемому ID существующего пользователя; пароль не нужен.
5. Войдите на сайте. В аккаунте появится ссылка «Управление каталогом».

Чтобы отозвать роль, удалите соответствующую строку `user_id` из `STEPPE_Admins`.
Права проверяются сервером при каждом обращении к панели. Настройки Vercel для
отдельного админского пароля не требуются. Панель использует текущую сессию входа.

## Добавление

1. Вставьте HTTPS-ссылку на товар и нажмите «Получить данные».
2. Импорт сначала ищет совпадение в последнем подтверждённом каталоге сборщика.
   Если совпадения нет, читает разрешённую страницу магазина и её JSON-LD.
3. Проверьте название, бренд, категорию, изображение, наличие размеров и закупочные
   цены. Можно изменить название/бренд/категорию и выбрать публикуемые размеры.
4. Если магазин сообщил одну фиксированную цену без размеров, размеры вводятся
   вручную с системой измерения: `EU 42, EU 43` или `US M 9, US M 10`.
   Вводите их только после проверки одинаковой цены и наличия каждого размера.
   Несколько разных цен без связи с размерами блокируют публикацию.
5. Отметьте подтверждение проверки и нажмите «Опубликовать».

Фото, исходные цены и курс берутся с сервера. Клиент не может подменить закупку
или цену продажи при публикации. Сохранённые черновики доступны после перезагрузки.

### Поддерживаемые ссылки

Точный список доменов и региональных путей хранится в `src/lib/manual-source.ts`:
Puma, Reebok, FILA, On, Brooks, adidas, Nike, New Balance, ASICS, Converse,
Vans, Under Armour, Skechers, Salomon, HOKA. Это список разрешённых адресов,
а не гарантия доступности автоматического импорта у всех 15 магазинов.

Импорт уважает robots.txt, не проходит CAPTCHA и не обходит блокировки.
Страницы, требующие браузерного JavaScript или не предоставляющие однозначную
фиксированную цену и наличие, могут не заполниться. В таком случае показывается
ошибка и товар не публикуется. Диапазоны AggregateOffer и ставки не принимаются.
Сторонние домены и произвольные перенаправления запрещены.

## Цены

Правило применяется ко всему живому каталогу, включая автоматические товары,
карточки, фильтры, корзину и список WhatsApp. Демонстрационные цены остаются демо.

- Закупка **меньше 20 000 ₸**: прибавляется **3 000 ₸**.
- Закупка **от 20 000 ₸ включительно**: прибавляется **12%**.
- Расчёт отдельно для каждого размера, после перевода цены источника в тенге.
- Округление до целого тенге: половина округляется вверх.
- 15 000 → 18 000 ₸; 19 999 → 22 999 ₸; 20 000 → 22 400 ₸; 25 000 → 28 000 ₸.

У заданного правила есть скачок на границе 20 000 ₸ — он сохранён буквально.
Исходная валюта, цена и курс остаются в базе. Наценка применяется при выдаче
товара, поэтому повторный сбор не накручивает её второй раз. Сопоставимая
зачёркнутая цена рассчитывается по тому же правилу; при отсутствии снижения
она и процент скидки скрываются. Пользовательские суммы из браузера не принимаются
при оформлении: сервер повторно проверяет товары и цены.

## Актуальность и удаление

- Если ручной товар совпадает по ссылке с новым снимком автоматического сборщика,
  закупка и наличие выбранных размеров обновляются из снимка. Название, бренд,
  категория пола и выбор размеров администратора сохраняются.
- Само добавление произвольной ссылки **не подключает её к браузерному сборщику**.
  Если товар не входит в его каталог, повторно получите данные по ссылке и
  опубликуйте свежий черновик. Данные старше `OFFER_MAX_AGE_HOURS` (по умолчанию
  36 часов) скрываются. Повторная публикация старого черновика не продлевает цену.
- «Удалить» скрывает товар из каталога и серверной проверки корзины. Автосбор
  не возвращает его: отметка хранится по ID и нормализованной ссылке.
- Товар можно вернуть во вкладке «Удалённые», пока исходная запись доступна.
  Восстановление не отменяет проверку срока актуальности. Старый автоматический
  товар, исчезнувший из снимков сборщика, может не отображаться в списке удалённых;
  отметка его скрытия продолжает действовать.
- Повторная публикация свежего черновика по той же ссылке заменяет предыдущую
  карточку и явно восстанавливает её, если она была удалена.
- Фото, исходные суммы, ссылки поставщиков и служебные сведения видит администратор
  в панели. Ссылки поставщиков не выдаются обычным посетителям.

## Проверки

```sh
npm run typecheck
npm test
npm run test:e2e -- tests/e2e/admin.spec.ts
```

Тесты покрывают границу наценки, цены размеров, корзину/WhatsApp, черновики,
публикацию, обновление из сборщика, дедупликацию, устойчивое удаление,
восстановление, отказы импорта и доступ администратора.
