# Что требуется для наполнения STEPPE

24.09.2026: приложение, SeaTable и расписание работают. Каталог реальных скидок не наполнен. Проверенный KicksDB Free возвращает рыночные цены StockX, но не подтверждает скидки магазина и доставку в Казахстан. По решению владельца эти данные не публикуются как предложения.

## Получение первого источника

1. Зарегистрировать сайт https://steppe-gray.vercel.app/ как площадку в партнёрской сети или обратиться непосредственно к магазину.
2. Получить одобрение магазина и доступ к автоматически обновляемому товарному фиду. Нужны текущая и предыдущая продажная цена (не только RRP), валюта, наличие, ссылки, изображения и подтверждение доступности конкретных товаров для Казахстана. Дата окончания акции необязательна: без неё выполняются обычные проверки дважды в сутки.
3. Передать URL экспорта и документацию формата. Секретный URL/токен сохранить в Vercel, не в публичном GitHub. Использовать настройки выбранного адаптера из [feeds.md](feeds.md).
4. После подключения выполнить workflow обновления, проверить число записанных предложений, цены, изображения, ссылки, размеры и время проверки на production. До успешного импорта не считать каталог запущенным.

## Проверенные пути, без обещания одобрения

- [FARFETCH через Admitad](https://www.admitad.com/ua/store/offers/farfetch-many-geos/) описывает ежедневные товарные фиды. Требуются одобрение, доступность программы для площадки и региональный экспорт KZ.
- [Инструкция Admitad по товарным фидам](https://admitad.useresponse.com/knowledge-base/article/product-feed-what-it-is-and-how-to-export-it-for-your-website_4).
- [Tennisnuts Affiliate Programme](https://www.tennisnuts.com/shop/customer-service/affiliates.html) принимает заявки. Публичная программа описывает партнёрский код, но наличие фида не подтверждено. Запросить его отдельно. [Доставка KZ](https://www.tennisnuts.com/shop/customer-service/international-orders/kazakhstan.html) не отменяет ограничений отдельных брендов. [Условия сайта](https://www.tennisnuts.com/shop/customer-service/terms-and-conditions.html) ограничивают копирование контента: импорт публичных страниц без разрешения не включён.
