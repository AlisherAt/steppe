# Подключение всех 15 брендов STEPPE

## Что уже работает

Цель — реальные скидки в магазинах США и Европы, с наличием и фиксированной ценой каждого размера. Котировки StockX и ставки не подходят. Проверка доставки в Казахстан не требуется. Клиент оформляет заявку через WhatsApp; ссылки поставщиков обычным пользователям не показываются.

В последнем проверенном полном запуске [GitHub Actions](https://github.com/AlisherAt/steppe/actions/runs/36048501402) получены предложения **Puma, Reebok, On, Brooks и FILA**. Следующий [запуск Puma/FILA](https://github.com/AlisherAt/steppe/actions/runs/36050320723) тоже завершился успешно. Это пять подключённых брендов, а не пятнадцать; ассортимент и остатки меняются.

Расписание уже настроено: `0 1,13 * * *` UTC — 06:00 и 18:00 по Алматы. GitHub Actions может запускать задания с задержкой. Результаты поступают в SeaTable, затем в каталог Vercel. Повторно настраивать расписание для каждого бренда не нужно. См. [автоматический сбор](scraper-automation.md).

## Какие десять брендов ещё не подключены

В последнем полном запуске диагностика показала:

- Nike — `ACCESS_HTTP_429`.
- adidas, New Balance, ASICS, Vans и Salomon — `PAGE_HTTP_403`.
- Converse — `ROBOTS_HTTP_403`.
- Under Armour — `ACCESS_CHALLENGE`.
- HOKA — `PAGE_HTTP_406`.
- Skechers — `SIZE_REQUEST_ROBOTS_DISALLOWED`: цена модели доступна, но необходимый запрос размеров запрещён правилами автоматического доступа. Публикации без подтверждённых вариантов нет.

Это результаты конкретного запуска, не утверждение о постоянной недоступности магазинов. Все 15 источников присутствуют в конфигурации сборщика, но наличие конфигурации не означает успешный импорт. Повторные запуски с тем же заблокированным способом доступа сами по себе проблему не решают.

## Следующий шаг для владельца

Владелец уже сообщил о полученных разрешениях. Теперь нужна **техническая часть согласованного доступа**: адрес API или товарного фида, документация авторизации и лимитов; либо инструкции магазина по допуску нашего сборщика. Передайте такие ответы без секретных значений. Если в ответе было только согласие, отправьте контактному лицу шаблон ниже.

Один мультибрендовый поставщик тоже подходит, если его реальный экспорт покрывает нужные бренды и размеры. До оплаты доступа нужно получить пример ответа и проверить ассортимент. Подписка на API сама по себе не гарантирует все 15 брендов.

### Готовый запрос на технический доступ

> Здравствуйте! Для STEPPE (https://steppe-gray.vercel.app/) ранее согласовали использование данных каталога. Подскажите технический способ подключения: URL API/товарного фида, документацию авторизации, лимиты и период обновления. Если доступ предполагает сбор публичных страниц, нужны инструкции по официальному допуску нашего сборщика и согласованные маршруты запросов.
>
> Нужны предложения вашего магазина США или Европы: артикул и цвет модели, название, изображение, валюта, текущая фиксированная цена и наличие каждого размера с указанием размерной системы, время проверки, предыдущая продажная цена и сроки акции, если доступны. Рекомендованную цену производителя (RRP/MSRP) просим обозначить отдельно от предыдущей цены магазина.
>
> Для проверки достаточно небольшого актуального примера, включая модель с несколькими размерами и отсутствующий размер. Планируем обновления дважды в день. Клиенты оставляют заявку на выкуп через WhatsApp; публичного перехода на сайт поставщика нет. Просим подтвердить совместимость согласованного использования с этой схемой.

Для обращения к мультибрендовому поставщику добавьте:

> Нужны бренды Nike, adidas, Puma, Reebok, New Balance, ASICS, Converse, Vans, Under Armour, Skechers, FILA, Salomon, HOKA, On и Brooks. Укажите, какие из них фактически доступны в вашем экспорте со скидками и остатками по размерам. Особый приоритет: Nike, adidas, New Balance, ASICS, Converse, Vans, Under Armour, Skechers, Salomon и HOKA.

## Проверенные альтернативы и их ограничения

- [BSTN](https://www.bstn.com/eu_de/affiliates) официально предлагает ежедневно обновляемый фид через Awin. Доступ ещё не получен. Покрытие всех 15 брендов, цены и остатки каждого размера нужно проверить на образце. Партнёрская программа с исходящими ссылками не подтверждает право использования для нашей схемы с WhatsApp. Зачёркнутые цены на сайте могут быть RRP — их нельзя автоматически считать прежней продажной ценой.
- [Retailed](https://docs.retailed.io/v1/introduction) требует ключ API. В опубликованном [примере Nike](https://docs.retailed.io/v1/api-reference/nike/product) есть размеры и текущая/начальная цена, но статус размера `ACTIVE` не доказывает остаток. [Пример Zalando](https://docs.retailed.io/v1/api-reference/zalando/product) не подтверждает одновременно обозначение размера, остаток и старую цену. Нужен тест настоящего ответа; готовая интеграция и покрытие всех брендов пока не подтверждены.
- [Shoe Palace](https://www.shoepalace.com/pages/terms-and-conditions) и [SportsShoes](https://www.sportsshoes.com/support/terms_and_conditions) ограничивают коммерческое копирование без отдельного разрешения. Разрешения от первоначальных официальных магазинов не распространяются автоматически на этих продавцов. Доступ к их фидам не получен.
- KicksDB/StockX отключён в плановом импорте: используемые рыночные котировки не соответствуют требованию фиксированных розничных цен по размерам. Сохранённая диагностическая интеграция не является способом включить оставшиеся бренды.

## Что происходит после получения доступа

1. Проверяем реальный ответ: регион магазина, SKU/цвет, размерную систему, наличие, фиксированную цену и основание скидки. Не выводим размер из непроверенного окончания артикула и не подменяем наличие статусом активности модели.
2. Подключаем адаптер к фактическому формату поставщика. Секреты хранятся только в серверных переменных Vercel или GitHub Actions — в зависимости от места выполнения адаптера. Их не добавляют в репозиторий или публичные `NEXT_PUBLIC_*` переменные.
3. Запускаем импорт вручную, проверяем цены нескольких размеров, изображения, корзину и время обновления в опубликованном каталоге.
4. Проверяем следующий запуск по существующему расписанию. Бренд считается подключённым после успешного импорта подтверждённых предложений, а не после добавления названия в фильтр.

В проекте есть адаптеры `retail-us` и `retail-eu` для [нормализованного JSON](fixed-price-sources.md). Их текущий контракт импортирует фиксированные цены, но не прежние цены и скидки. Для скидочного фида потребуется добавить соответствующее сопоставление и проверку. Загрузка произвольного CSV в переменную URL этого не заменяет. Общие партнёрские парсеры также не отменяют проверку наличия и цены каждого размера перед публикацией.
