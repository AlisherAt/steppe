# Подключение разрешённых товарных фидов

## Доступ к Nike и Adidas

У [Nike](https://www.nike.com/help/a/nike-affiliate-program/app) автоматический товарный фид указан среди возможностей одобренных партнёров. Для приведённой американской программы заявка подаётся через CJ Affiliate. У [Adidas](https://www.adidas.com/us/help/us-company-information/what-is-our-affiliate-program) описана программа с Impact Radius. Это примеры официальных региональных программ, а не обещание доступности для Казахстана. Уточните у менеджера программы территорию распространения, право показывать цены/изображения, deep links и доставку.

После одобрения получите URL и credentials. Поддерживаются **JSON v1, YML, Awin CSV, Google Merchant XML/CSV**. Для других схем CJ/Impact потребуется нормализация. Формат выбирается через `*_FEED_FORMAT`. Не указывайте HTML-страницу вместо фида. Код не обращается к закрытым endpoint Nike/Adidas.

Для каждого источника используются отдельные переменные с префиксом `NIKE` или `ADIDAS`:

- `*_FEED_URL`: полный HTTPS URL JSON-фида, без перенаправлений. Query-токен допустим, но предпочтительнее заголовок Bearer; URL никогда не логируется приложением.
- `*_FEED_HOSTS`: точные домены endpoint через запятую. Без wildcard, протокола и путей.
- `*_FEED_TOKEN`: необязательный Bearer-токен; для иной схемы авторизации расширьте транспорт адаптера, не публикуйте credentials в браузер.
- `*_FEED_PERMISSION`: непустая внутренняя ссылка/номер разрешения или договора. Само заполнение переменной не даёт права использовать чужие данные — это должен подтвердить оператор.
- `*_PRODUCT_HOSTS`: точные разрешённые хосты исходных product/deep links. При разрешённых affiliate deep links добавьте домен партнёрской сети.
- `*_FEED_KZ_ONLY=true`: оператор получил подтверждение, что выгрузка содержит **только товары с доставкой в Казахстан**, включая ограничения брендов и продавцов. Общей надписи «доставка по миру» недостаточно. Если такого экспорта нет, источник оставьте отключённым.
- `*_DELIVERY_POLICY_URL`: официальная HTTPS-страница условий доставки на разрешённом `*_PRODUCT_HOSTS`; ссылка показывается пользователю.
- `*_FEED_FRESHNESS_CONFIRMED=true`: поставщик подтвердил, что URL отдаёт регулярно обновляемый полный экспорт. Особенно важно для Google XML/CSV без стандартной даты генерации. Фактическое время скачивания не выдаётся за дату изменения товара у продавца.
- `PRODUCT_IMAGE_HOSTS`: разрешённые точные хосты изображений, общие для источников. Изменение требует нового Vercel deploy.

По умолчанию источники отключены до заполнения всех обязательных полей. Их можно приостановить в `sources.paused` независимо друг от друга. Подтверждайте условия API, частоту запросов и разрешения на изображения до подключения. Если будете добавлять адаптер публичных страниц, отдельно проверьте robots.txt и условия сайта; текущие адаптеры читают только разрешённые фиды и ничего не скрейпят.

## Контракт v1

Следующий JSON — **пример формата, не реальное предложение**. Дата должна быть актуальной в настоящем фиде. Не выдавайте этот пример за live-источник.

```json
{
  "version": 1,
  "complete": true,
  "generatedAt": "2026-09-24T06:00:00+05:00",
  "products": [
    {
      "id": "stable-merchant-sku-colorway",
      "brand": "Nike",
      "name": "Название из разрешённого фида",
      "productUrl": "https://www.nike.com/t/real-product-path",
      "imageUrl": null,
      "originalPrice": "120.00",
      "salePrice": "84.00",
      "currency": "USD",
      "sizes": ["40", "41", "42.5"],
      "gender": "unisex",
      "category": "На каждый день",
      "available": true
    }
  ]
}
```

- `complete: true` обязателен: это полный каталог источника, а не страница пагинации. Все страницы исходного экспорта нужно собрать перед публикацией. Пустой `products: []` с подтверждённым полным снимком деактивирует предыдущие предложения.
- `generatedAt`: ISO 8601 с часовым поясом; максимум 36 часов давности, максимум час в будущем.
- Денежные значения — десятичные **строки**, без символов валют, пробелов и разделителей тысяч. До четырёх знаков после точки. Обе цены должны быть положительными; акционная не больше исходной. Товары без скидки не публикуются.
- `currency`: трёхбуквенный код ISO 4217; при отсутствии курса вся загрузка этого магазина завершается ошибкой. Исходные значения сохраняются в `offers.payload.originalPrice`, `salePrice`, `currency`.
- `sizes`: только реально доступные размеры в **EU**. Не переводите US/UK в EU наугад: используйте официальную таблицу бренда/варианта или оставьте массив пустым. Пустой список отображается как «Размер у продавца».
- `id`: стабильный ID модели/расцветки. Разные расцветки/варианты с разными ценами должны иметь разные ID и различные product URL. Если у каждого размера своя цена, выгружайте отдельные варианты с точными размерами и URL.
- `gender`: `men`, `women`, `unisex`, `kids`. Неизвестный пол нормализуется оператором в `unisex`; желательно сохранить точное значение источника.
- `category`: человекочитаемая категория на русском. `name` — название модели из источника; не переводите товарные знаки.
- `available: false` исключает товар. При отсутствии поля подразумевается true, поэтому нормализатор должен явно передавать статус.
- `imageUrl`: HTTPS с разрешённого хоста либо null; при отсутствующем/неработающем изображении есть нейтральная заглушка. Используйте только изображения, право на отображение которых предоставил источник.

## Надёжность и ограничения

Повторы внутри одного фида схлопываются по merchant ID и канонической ссылке без `utm_*`, `gclid`, `fbclid`, `affiliate`, `aff_id`. Совпадающие цены объединяют размеры. Конфликтующие цены, валюты, названия или наличие отклоняют загрузку, чтобы не публиковать неверные варианты. Хранимая уникальность — `(source_id, external_id)`, стабильный ID сайта — SHA-256 от источника и merchant ID. Одна модель у разных продавцов остаётся двумя предложениями.

Разрешены только HTTPS, точные хосты, публичные IP; переадресации блокируются. Ошибки авторизации, CAPTCHA/HTML вместо данных и некорректный формат не обходятся. Максимум 20 MB после распаковки gzip, 20 000 исходных строк XML/CSV и 1000 отобранных товаров на фид. Превышение отклоняет снимок без изменения базы. Большие источники разделяйте на стабильные самостоятельные выгрузки.

Каждый магазин обновляется атомарно. При успешном пустом фиде старые записи скрываются; при ошибке остаются до срока актуальности `OFFER_MAX_AGE_HOURS` (по умолчанию 36). Поле `sources.offer_count` — число при последней успешной загрузке, а не обещание текущей доступности после истечения срока.

Для нового API реализуйте интерфейс `SourceAdapter`, не меняя каталог/корзину/SQL. Если у поставщика более строгая частота запросов, уменьшите количество retry и согласуйте расписание с договором.
