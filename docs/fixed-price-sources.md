# Фиксированные цены для выкупа: США и Европа

## Текущее состояние

KicksDB/StockX отключён в реестре планового импорта. Старые рыночные предложения не показываются в live-каталоге и не принимаются при оформлении, даже из сохранённой корзины. Данные не удаляются безвозвратно.

Есть отдельные адаптеры retail-us и retail-eu для **нормализованного JSON-фида**, а не готовые неавторизованные интеграции со всеми перечисленными магазинами. Доступ к новым фидам пока не получен. Браузерный сбор пяти полей цены не заменяет этот контракт.

## Проверенные кандидаты (24.09.2026)

- eBay Browse API: https://developer.ebay.com/api-docs/buy/api-browse.html — позволяет отличать FIXED_PRICE от AUCTION. Нужны production-доступ и отдельные вариации getItem, страна нахождения конкретного товара, доступность и цена. Старый адаптер eBay в проекте не даёт этих гарантий и отсекается при публикации/заказе.
- BSTN, Европа: https://www.bstn.com/eu_de/affiliates — Awin, официально заявлен ежедневный товарный фид. Нужна проверка цены/остатка каждого размера и разрешение на использование в собственной витрине без исходящих партнёрских ссылок.
- END., Великобритания: https://www.endclothing.com/gb/affiliate-program — Impact, официально заявлены product feeds. Исключать raffles/launches; фид и право перепродажи требуют согласования.
- Brandsdistribution: https://www.brandsdistribution.com/en/cms/developers — API для авторизованных dropshipper-пользователей. Требуются учётная запись, ключ, проверка ассортимента кроссовок и страны склада; наличие US-домена не доказывает склад США.
- Zappos не подходит для этой схемы: https://www.zappos.com/associates-program — программа прямо запрещает reseller/dropshipper activity.

StockX поддерживает Buy Now: https://stockx.com/help/articles/How-do-I-buy-on-StockX . Но используемый lowest_ask не подтверждает итоговую стоимость приобретения и расположение пары.

## Контракт подключения

Переменные RETAIL_US_* / RETAIL_EU_* в .env.example. FEED_URL — HTTPS адрес разрешённого полного JSON-экспорта; FEED_HOSTS и PRODUCT_HOSTS — точные хосты; FEED_TOKEN — Bearer, если нужен; RESELLER_PERMISSION — запись о согласованном использовании. PRODUCT_IMAGE_HOSTS — хосты изображений.

Фид: version=1, complete=true, generatedAt=ISO timestamp, products=array. Каждая модель:

- id, name, brand, sku (необязательный), productUrl, imageUrl (nullable);
- purchaseType="fixed", warehouseCountry — фактическая страна отгрузки;
- currency, gender (men/women/kids/unisex);
- variants: id, sizeEU, price (десятичная строка в исходной валюте), stock (целое), checkedAt (ISO).

Размеры должны быть однозначными, без дубликатов. В импорт попадают только stock>0 и проверки моложе 36 часов. Американский поток принимает warehouseCountry=US, европейский — страны из EUROPE_COUNTRIES в src/lib/orderable.ts. Цена минимального варианта используется только как «от»; выбранный размер определяет цену корзины. Предыдущая цена не придумывается: текущий контракт импортирует фиксированные цены без заявления скидки.

SeaTable использует существующие JSON-snapshot таблицы. Для альтернативного Supabase применить миграцию 202609240006_fixed_retail.sql; активный production использует SeaTable.

Обновление дважды в день не резервирует товар. Для гарантии закупочной цены нужно отдельное подтверждение/резерв у поставщика перед оплатой клиента; текущий сайт не принимает платежи.
