# Курсы и конвертация

## НБРК — основной провайдер

`RATE_PROVIDER=nbk` использует `https://nationalbank.kz/rss/rates_all.xml`, опубликованный в [официальной документации RSS НБРК](https://nationalbank.kz/ru/page/RSS). Курс за одну единицу валюты вычисляется как `description / quant`: например, значение за 100 иен делится на 100. `pubDate` интерпретируется как дата действия в Казахстане (UTC+5); отдельно сохраняется фактическое время получения.

Реальный запрос проверен 24 сентября 2026 года. Для повторной проверки выполните `npm run check:rates`. Скрипт читает переменные окружения процесса; `.env.local` Next.js загружает сам, а для проверки с этим файлом можно использовать `node --env-file=.env.local --import tsx scripts/check-rates.ts`.

Срок действия ограничен `RATE_MAX_AGE_HOURS` (по умолчанию 120 часов для выходных/праздников). Будущий курс более чем на час и просроченный курс отклоняются. Если срок нужно увеличить для официальных праздничных дней, оператор делает это явно. Курс не переносится с произвольной старой даты автоматически.

В карточке указаны фактические `source`, `asOf`, `fetchedAt` и время пересчёта. Курс НБРК не равен карточному курсу банка и не называется курсом Kaspi.

## Авторизованный JSON, в том числе Kaspi

Публичный разрешённый API курсов Kaspi не подтверждён. Не подставляйте угаданные адреса, не извлекайте сессии мобильного приложения. Получив разрешённый источник, задайте:

```dotenv
RATE_PROVIDER=authorized-json
AUTHORIZED_RATE_URL=https://your-authorized-provider.example/rates
AUTHORIZED_RATE_HOSTS=your-authorized-provider.example
AUTHORIZED_RATE_TOKEN=
AUTHORIZED_RATE_LABEL=Точное название поставщика курса
AUTHORIZED_RATE_PERMISSION=Идентификатор разрешения/договора
```

JSON-контракт (значения только пример, не действующий курс):

```json
{
  "asOf": "2026-09-24T06:00:00+05:00",
  "rates": { "USD": "500.123456", "EUR": "550.00" }
}
```

Каждое значение означает **KZT за 1 единицу валюты**. В контракте допускаются положительные десятичные строки до 12 знаков после точки, не более 10 000 000 KZT за единицу. Если разрешённый Kaspi API имеет другой формат/аутентификацию, добавьте нормализатор в `loadRates` либо предоставьте свой серверный endpoint с этим контрактом. Называйте источник Kaspi только при реальном получении курса Kaspi по разрешённому каналу.

## Ручной курс и резерв

Для ручного режима задайте `RATE_PROVIDER=manual`, `MANUAL_RATES_JSON`, `MANUAL_RATE_AS_OF`, `MANUAL_RATE_LABEL`. В JSON нужны реальные проверенные значения, например структура `{"USD":"…","EUR":"…"}`; многоточие необходимо заменить действующим десятичным курсом. Дата — ISO 8601 с часовым поясом; за её свежесть отвечает оператор.

`RATE_FALLBACK=none` — значение по умолчанию. Чтобы разрешить ручной резерв при отказе основного провайдера, задайте `RATE_FALLBACK=manual` и все ручные поля. Резерв проходит такую же проверку свежести и выводится с подписью «(резервный)». Неизвестный или отсутствующий курс не заменяется выдуманным числом.

В настройках Vercel JSON вводится без внешних одинарных кавычек; в `.env.local` значение можно заключить в одинарные кавычки. После изменения переменных Vercel выполните redeploy, код менять не требуется.

## Расчёт и хранение

`Decimal.js` считает по десятичным значениям. `KZT = sourceAmount × rate`, округление половины вверх до целого тенге. Процент скидки вычисляется по исходным ценам магазина и округляется вниз; конвертация не изменяет заявленную скидку. Оригинальная и акционная цены конвертируются одним и тем же курсом. Не допускаются нулевые/отрицательные цены и валютные курсы, NaN, Infinity и переполнение безопасного целого.

`offers.payload` хранит исходные строки, валюту, обе цены в тенге и снимок курса; `exchange_rates` хранит историю курсов, используемых успешными обновлениями. Изменившийся курс применяется при следующем успешном импорте. Для исходных цен KZT применяется ровно 1 с подписью «Цена магазина в тенге»; сеть не требуется для их конвертации.

Если валютный сервис недоступен, товары в KZT всё ещё могут обновляться. Магазин с хотя бы одной требующей отсутствующего курса валютой получает ошибку: предыдущий согласованный снимок сохраняется целиком до истечения срока актуальности. Таким образом, частичная загрузка не скрывает товары с временно недоступной конвертацией.
