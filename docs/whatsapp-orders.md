# Заказы через WhatsApp

Получатель заказов: **+7 707 922 3074**. Публичный контакт задан в `src/lib/store-contact.ts` и используется одновременно сервером и интерфейсом. Дополнительные переменные Vercel и ключ WhatsApp Business API не требуются. Старая переменная `WHATSAPP_ORDER_PHONE` больше не используется; её можно удалить из настроек окружения.

Кнопка «Оформить в WhatsApp» вызывает POST `/api/checkout/whatsapp`. Сервер получает только ID и размеры, повторно проверяет каталог и формирует список из актуальных данных: модель, размер, одна пара каждой позиции, цена KZT, код товара STEPPE, ориентировочный итог. Цены из браузера не принимаются. Демо, исчезнувшие предложения, недоступные размеры и дубликаты отклоняются. Интерфейс проверяет домен и номер получателя перед переходом.

Открывается официальная ссылка `https://wa.me/<номер>?text=<сообщение>`. Пользователь сам подтверждает отправку в WhatsApp. Это запрос на оформление; деньги на сайте не списываются, заказ в базе не регистрируется, корзина не очищается. Наличие и окончательная стоимость согласуются в переписке. Слишком длинная ссылка отклоняется с предложением разделить заказ — товары не обрезаются молча.

Проверка: `npm test` и `npm run test:e2e`. Тесты не отправляют сообщения и не связываются с получателем.
