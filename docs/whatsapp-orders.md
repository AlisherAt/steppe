# Заказы через WhatsApp

Добавьте `WHATSAPP_ORDER_PHONE` в `.env.local` и Vercel → Settings → Environment Variables → Production. Значение — номер WhatsApp с кодом страны, без пробелов и знака +. Затем выполните Redeploy. Ключ WhatsApp Business API не требуется.

Кнопка «Оформить в WhatsApp» вызывает POST `/api/checkout/whatsapp`. Сервер получает только ID и размеры, повторно проверяет каталог и формирует список из актуальных данных: модель, размер, одна пара каждой позиции, цена KZT, код товара STEPPE, ориентировочный итог. Цены из браузера не принимаются. Демо, исчезнувшие предложения, недоступные размеры и дубликаты отклоняются. Ошибка конфигурации показывается без переадресации на случайный номер.

Открывается официальная ссылка `https://wa.me/<номер>?text=<сообщение>`. Пользователь сам подтверждает отправку в WhatsApp. Это запрос на оформление; деньги на сайте не списываются, заказ в базе не регистрируется, корзина не очищается. Наличие и окончательная стоимость согласуются в переписке. Слишком длинная ссылка отклоняется с предложением разделить заказ — товары не обрезаются молча.

Проверка: `npm test` и `npm run test:e2e`. Тесты не отправляют сообщения и не связываются с получателем.
