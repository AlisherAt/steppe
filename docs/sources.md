# Зарубежные источники и автоматическое обновление

Проверка официальных материалов: **24 сентября 2026**. Наличие магазина в этом списке не означает действующий доступ к его товарам. В окружении проекта нет партнёрских ключей: ни один live-фид не активирован. Реальные товары и цены не выдумываются.

## Приоритетные магазины

- **FARFETCH**: [условия региональной версии KZ](https://www.farfetch.com/kz/orders-and-shipping/). [Партнёрская программа Admitad](https://www.admitad.com/ua/store/offers/farfetch-many-geos/) заявляет товарные фиды. Подайте заявку на программу для своей площадки, согласуйте географию Казахстана и получите полный экспорт с доступностью SKU для KZ. Используйте профиль `farfetch`, префикс `FARFETCH`, выберите реальный формат экспорта. По умолчанию YML; предоставленный сетью другой формат нужно выбрать или преобразовать. Условия отдельных бутиков/брендов могут различаться.
- **YOOX**: [версия для Казахстана](https://www.yoox.com/kz) и [выбор страны](https://www.yoox.com/Footer/Countries). Подготовлен профиль `yoox` / `YOOX`. Наличие страны в интерфейсе не доказывает доставку каждого товара: нужен разрешённый региональный фид с доступностью. Публичный endpoint для свободной загрузки без партнёрского доступа не подтверждён.
- **Tennisnuts**: [отдельная страница доставки в Казахстан](https://www.tennisnuts.com/shop/customer-service/international-orders/kazakhstan.html) описывает отправку и ориентир 5–8 дней после отправки. Подготовлен профиль `tennisnuts` / `TENNISNUTS`. Для автоматического импорта запросите у магазина право отображать ассортимент, изображения, цены и полный обновляемый экспорт. Публичный API/фид не подтверждён. Не подключайте HTML страницы вместо фида.
- **eBay**: реализован Browse API, production OAuth `client_credentials`, автоматическое обновление токена. Нужны Developer application и [одобренный production-доступ Buy API](https://developer.ebay.com/api-docs/buy/buy-requirements.html). Заполните `EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET`, `EBAY_API_PERMISSION` (номер/ссылка разрешения). `EBAY_QUERY=sneakers` задаёт область поиска. [Фильтры Browse](https://www.developer.ebay.com/api-docs/buy/static/ref-buy-browse-filters.html): `deliveryCountry:KZ`, `conditionIds:{1000}`, `buyingOptions:{FIXED_PRICE}`. Дополнительно проверяются положительная STP-скидка, бренд, рейтинг продавца ≥98% и ≥100 отзывов, срок объявления. MAP-цены исключены. Получается до **200 новых результатов за запуск**; это ограниченная подборка, а не весь eBay. Размеры неизвестны до перехода к объявлению. Рейтинг не является гарантией подлинности; учитывайте условия продавца, возврата и защиты покупателя. API-фильтр страны не проверяет ваш конкретный индекс/адрес, это уточняется при покупке.

**Не добавлены в качестве проверенной доставки:** Slam Jam — [официальная политика](https://slamjam.com/en-us/policies/shipping-policy) прямо указывает приостановку доставки в Казахстан. Для END., SSENSE, BSTN, Footshop и ASOS недостаточно общей фразы «worldwide» или списка стран без подтверждения доступности конкретных товаров; активные импортеры под них не включены. Amazon/AliExpress также не включены без подтверждённых разрешений API, продавцов и доставки конкретных объявлений. Сервисы пересылки не считаются прямой доставкой магазина.

## Партнёрские сети — транспорт данных

Это не продавцы. Выберите **один магазин** и укажите его настоящее название в `*_STORE_NAME`. Для нескольких магазинов создайте отдельные профили с независимыми ID, разрешениями, паузой и журналом.

- **Admitad** (`ADMITAD`, по умолчанию `yml`): после подключения рекламодателя получите **полный** товарный экспорт через [инструменты фидов](https://support.admitad.ru/article/ru/86.html). Не используйте ссылку «только изменения»: снимок заменяет каталог источника.
- **Awin** (`AWIN`, `awin-csv`): [Create-a-Feed](https://help.awin.com/developers/docs/downloading-feeds-using-create-a-feed) позволяет сформировать URL CSV для разрешённого рекламодателя. Задайте сам URL, включая выданный ключ (он хранится только на сервере). gzip поддерживается. Нужны поля `merchant_product_id` или `aw_product_id`, `product_name`, `brand_name`, `search_price`, `product_price_old`, `currency`, `in_stock`, `last_updated`, `aw_deep_link` или `merchant_deep_link`, изображение при наличии. **`rrp_price` не используется**: рекомендуемая цена не подтверждает скидку с прежней цены продавца. Отсутствие реальной прежней цены означает отсутствие скидочной карточки.
- **«Где Слон?»** (`GDESLON`, `yml`) сохранён как дополнительный технический коннектор. [Документация XML API](https://gdeslon.ru/faq/20/). Для этого адаптера нужен **полный YML** конкретного магазина; страница поиска API не подходит. Включайте только проверенного зарубежного продавца с доставкой KZ.
- **Прямой экспорт** (`RETAILER`, `yml`) или **Google Merchant** (`GOOGLE_FEED`, `google-xml`). Это файл продавца, а не доступ к поисковой выдаче Google Shopping. XML — RSS с `g:*` полями; CSV — аналогичные имена без префикса. И цена `price`, и `sale_price` обязательны для скидочного товара, например `100.00 USD`. `availability=in_stock`, `condition=new` если указано. `sale_price_effective_date` учитывается. Размеры читаются только при `size_system=EU`.

## Обязательная настройка каждого фида

Кроме URL/токена/хостов и разрешения из [feeds.md](feeds.md), укажите:

```dotenv
FARFETCH_FEED_KZ_ONLY=true
FARFETCH_FEED_FRESHNESS_CONFIRMED=true
FARFETCH_DELIVERY_POLICY_URL=https://www.farfetch.com/kz/orders-and-shipping/
```

Эти значения допустимы **только после подтверждения магазином** регулярного полного экспорта товаров с доставкой KZ. Широкая выгрузка международного каталога без проверки региона не подходит. Код требует эти настройки, сохраняет основание `merchant-feed` и время проверки; БД не принимает активные товары без данных доставки. Явные страны товара имеют приоритет: JSON `deliveryCountries: ["US"]` исключит его даже при KZ-фиде. Отсутствующее поле допустимо только благодаря договорённости о KZ-экспорте. Google XML читает `g:shipping/g:country`; YML поддерживает дополнительное поле `deliveryCountries` с ISO-кодами через запятую. Для стандартного YML/Awin/Google CSV, где нет однозначной информации о странах, используйте именно KZ-выгрузку.

Дополнительные параметры для любого префикса:

- `*_FEED_FORMAT=json|yml|awin-csv|google-csv|google-xml`.
- `*_FEED_TIMEZONE=+03:00` — часовой пояс поставщика для дат без смещения, не угадывайте его. YML `yml_catalog@date` и Awin `last_updated` проверяются на давность ≤36 часов. Google-фиды не имеют обязательной даты генерации: проверка их регулярного обновления — обязанность поставщика/оператора.
- `*_FEED_SIZES_EU=true` — только если источник гарантирует EU для неуказанной системы. Явный US/UK не преобразуется. Awin-размеры остаются неизвестными.
- `*_FEED_CATEGORY=...` — необязательная подстрока категории, по умолчанию отбор по словам sneakers/trainers/running shoes/кроссовки/кеды; аксессуары исключаются.
- `*_FEED_ALLOW_EMPTY=true` — разрешить полностью пустую XML/CSV-выгрузку. Без этого пустой файл считается ошибкой. Непустой корректный фид с нулём подходящих скидок означает успешный пустой снимок.

## Ещё магазины без изменения кода

```dotenv
ADDITIONAL_SOURCES_JSON=[{"id":"another-store","name":"Название продавца","prefix":"ANOTHER","format":"yml"}]
ANOTHER_FEED_URL=
ANOTHER_FEED_HOSTS=
ANOTHER_FEED_PERMISSION=
ANOTHER_PRODUCT_HOSTS=
ANOTHER_DELIVERY_POLICY_URL=
ANOTHER_FEED_KZ_ONLY=false
ANOTHER_FEED_FRESHNESS_CONFIRMED=false
```

До 20 дополнительных источников. Для каждого заполните отдельные настройки, включите флаги после подтверждения. Реальные токены не добавляйте в Git. Справочник из 78 брендов не является ограничением: любые новые марки из разрешённых фидов автоматически появляются в каталоге/фильтрах при наличии действующих товаров.

## Автоматика после однократного подключения

1. Примените все миграции Supabase и разместите серверные настройки в Vercel.
2. Добавьте два секрета Vault и выполните `supabase/schedule.sql`, как описано в README.
3. Выполните один контрольный запуск. Нужен `success` у магазина, а не только HTTP 200 или `needs_configuration`.
4. Далее каждые 12 часов (06:00 / 18:00 Алматы) импортируются новые цены, размеры и наличие, пересчитывается KZT, обновляются карточки и деактивируются исчезнувшие товары. Покупательские визиты для работы расписания не нужны. Сам планировщик ещё не активирован в облаке без подключения вашего Supabase/Vercel.
5. Контролируйте `refresh_runs`, `last_success_at` и HTTP-ответ задачи. Истёкшие доступы нужно продлевать; при сетевом сбое срабатывают повторы, старые карточки скрываются через 36 часов. Для более частых обновлений измените cron-выражение в рамках лимитов поставщика.

Публикация не включает стоимость международной доставки/пошлины в цену кроссовок. Итоговую сумму, адрес доставки, размер и условия возврата подтверждает магазин.
