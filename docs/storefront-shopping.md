# Обновлённая витрина STEPPE

## Что изменилось

- Компактный первый экран и карточки: фото, название, одна строка описания, цена и выбор размера.
- Размер выбирается кнопками внутри открытого товара. Цена зависит от выбранного варианта; добавление в корзину находится в том же окне. На телефоне панель покупки закрепляется снизу.
- Избранное: `/favorites`, до 50 товаров в localStorage (`steppe.favorites.v1`). Сервер заново получает доступные карточки; пропавшие из каталога позиции можно оставить до возвращения или убрать. Ошибка загрузки не удаляет список. Между устройствами список не синхронизируется.
- Нижняя навигация на телефоне, чипы активных фильтров с отдельным удалением, фотографии одежды в вертикальном формате.
- Корзина с миниатюрами и сменой размера без удаления товара. Доступные варианты и цены загружаются через `/api/cart-check`. Совпадающие модель и размер объединяются в одну позицию. Перед переходом в WhatsApp сервер повторно проверяет заказ.
- Кнопка «Отправить заказ в WhatsApp» открывает подготовленное сообщение. Покупатель сам отправляет его в чате; сайт не списывает деньги.
- Единые скругления и спокойные переходы. `prefers-reduced-motion` отключает движение.

## Образы из каталога

Раздел «Вместе — ещё интереснее» загружается при приближении к нему. Ссылка «Готовые образы» находится на первом экране.

`GET /api/outfits` собирает обувь, верх и брюки из доступного ассортимента, отдельно для двух разделов: «Для неё» и «Для него». Допускаются товары унисекс. Это автоматические идеи сочетаний по категории, цвету и цене, а не подтверждение совместимой посадки: размер каждой вещи покупатель выбирает отдельно.

- «Спокойная база»: только распознанные нейтральные цвета.
- «Чёрное + белое»: расцветки, проходящие существующий фильтр monochrome.
- «На учёбу и в город»: повседневные кроссовки, верх, брюки.
- «Образ до 50 000 ₸»: сумма даже самых дорогих доступных размерных вариантов не выше 50 000 ₸. Без стоимости доставки, которая согласуется отдельно.

В сборку не входят демотовары, товары без фото и размеров, детские модели, аксессуары и специализированная спортивная обувь. При неполном комплекте подборка не публикуется. Приоритет у вещей с несколькими доступными размерами. Ссылки поставщиков удаляются из публичного ответа тем же `publicProduct`, что и в каталоге. Наценка и налог уже включены существующим серверным расчётом; повторно они не прибавляются.

Для GitHub используется весь текущий разрешённый каталог. Для другого провайдера берутся первые две страницы каждого раздела, отсортированные по цене. Образы пересобираются из свежего каталога при запросе; кеш ответа — 60 секунд.

## Проверки

- `npm test -- tests/shopping.test.ts tests/core.test.ts tests/size-prices.test.ts tests/price-rounding.test.ts`
- `npm run build` (в окружениях без записи глобальных настроек: `NEXT_TELEMETRY_DISABLED=1`).
- `npx playwright test tests/e2e/shopping.spec.ts tests/e2e/size-guide.spec.ts tests/e2e/product-gallery.spec.ts tests/e2e/market.spec.ts tests/e2e/storefront.spec.ts tests/e2e/size-filter.spec.ts`

Для проверки на уже запущенном локальном сервере задайте `PLAYWRIGHT_BASE_URL`, например `http://localhost:3120`. По умолчанию конфигурация сама запускает тестовый сервер на 3100. Браузерные тесты используют изолированные карточки и перехватывают переход в WhatsApp: сообщения покупателям или продавцу не отправляются.
