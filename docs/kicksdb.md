# KicksDB — рабочий каталог рынка США

Владелец разрешил показывать текущие цены без подтверждения скидки и без проверки доставки KZ. Используется Standard API StockX, market=US, currency=USD. Это рынок цены, не страна склада.

Ключ KICKS_API_KEY хранится только на сервере. Адаптер kicks-stockx подключается автоматически при наличии ключа, выполняется существующим планировщиком дважды в сутки. 8 брендов × 1 запрос × 2 запуска × 31 день = 496 запросов в месяц без ручных запусков; limit=8 товаров на бренд. Квота аккаунта общая с другими приложениями. Детальные запросы и платный Real-Time API не используются. При ошибке любой страницы снимок не публикуется; повтор будет по расписанию.

Nike, Adidas, New Balance, ASICS, Jordan, Puma, Reebok, Converse. Повторяющиеся ID объединяются. Выборка не является полным каталогом StockX.

Для модели выбирается минимальный положительный lowest_ask среди вариантов US/USD с total_asks>0 и известным размером EU. Публикуются только размеры по этой цене. Скрытые варианты и цены старше 36 часов исключаются. В карточке сохраняются артикул, рынок, время данных источника и время пересчёта. originalPrice/originalKzt=null, discount=0: прежняя цена не изобретается и не зачёркивается.

Тест соединения: npm run check:kicks. Он не публикует товары. Импорт выполняется защищённым /api/cron/refresh. Пауза — checkbox paused у kicks-stockx в SeaTable. Дополнительных колонок SeaTable не требуется; Supabase требует миграцию 202609240005_us_market.sql.

Фото разрешены только с images.stockx.com. Ссылки StockX и партнёрские stockx.pvxt.net принимаются с проверкой назначения. Данные KicksDB могут отставать от площадки; окончательная цена определяется продавцом.
