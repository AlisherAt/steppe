# KicksDB — архивная диагностическая интеграция

**KicksDB/StockX отключён в реестре планового импорта.** Наличие `KICKS_API_KEY` не включает его в каталог. Рыночные предложения также исключены из оформления заказа, включая старые сохранённые корзины. Для текущей схемы нужны фиксированные розничные цены и наличие каждого размера; см. [подключение всех 15 брендов](live-catalog-activation.md) и [контракт фиксированных цен](fixed-price-sources.md).

## Что осталось в коде

Сохранены адаптер Standard API StockX и команда `npm run check:kicks` для диагностики соединения. Команда требует серверный `KICKS_API_KEY` и не публикует товары. Не следует включать адаптер обратно только ради увеличения числа брендов.

Ранее интеграция использовала `market=US`, `currency=USD` и минимальный положительный `lowest_ask` среди вариантов с `total_asks>0` и известным размером EU. Рыночная котировка не подтверждает фиксированную цену выкупа у розничного магазина, скидку и страну склада. Прежняя цена не вычислялась: `originalPrice/originalKzt=null`, `discount=0`.

Активный планировщик `/api/cron/refresh` использует реестр `src/lib/server/sources.ts`, в котором этого адаптера нет. Настройка паузы старого источника в SeaTable не добавляет его обратно. Ранее сохранённые данные не удаляются безвозвратно.

Документация провайдера: [аутентификация](https://docs.kicks.dev/guides/authentication), [источники](https://docs.kicks.dev/guides/sources), [OpenAPI](https://api.kicks.dev/openapi.json).
