# KicksDB

Проверено 24.09.2026: предоставленный ключ Free принимается Standard API (`HTTP 200`). Запрос `GET /v3/stockx/products` с `display[variants]=true`, `display[prices]=true`, `market=US` возвращает карточки и цены StockX по размерам, включая валюту и время обновления варианта. Полный ответ и ключ не записываются в Git.

## Настройка

Секрет `KICKS_API_KEY` хранится в `.env.local` для разработки и Vercel Production для сервера. Не используйте `NEXT_PUBLIC_` и не передавайте ключ браузеру. Проверка: `npm run check:kicks` (один запрос, один товар). Она выводит только сводку и не публикует предложения.

Реализован проверяющий структуру ответа клиент `src/lib/server/kicks.ts`. Сохраняются исходные цены вариантов, валюта, рынок, тип размера и время источника. Размер US не выдаётся за EU. Число запросов ограничено одной попыткой на вызов; автоматические циклы и запросы реального времени не используются. Ошибка доступа или лимита возвращается без ключа и тела ответа.

## Ограничение публикации

Проверенный ответ не содержит предыдущую продажную цену магазина, дату окончания скидки или подтверждение доставки предложения в Казахстан. `lowest_ask` — рыночная цена предложения. Она не превращается автоматически в скидку. `updated_at` не означает дату окончания акции. Рынок US не означает доставку KZ.

Поэтому эти результаты пока **не импортируются в STEPPE_Offers и не запрашиваются планировщиком**: повторные запросы расходовали бы квоту, не создавая подходящих предложений. Для включения в основной каталог нужны дополнительные подтверждённые данные скидки и доставки. Другой вариант — отдельно согласованный справочный раздел рыночных цен без утверждения о скидке или доставке.

Shopify endpoints отмечены в OpenAPI как доступные платным пользователям. Их схема содержит текущую цену варианта, но не доказывает старую продажную цену или доставку KZ. Покупка тарифа сама по себе не решает эти вопросы; платная подписка не включалась.
