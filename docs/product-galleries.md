# Галереи и подборки каталога

Карточка показывает до 10 подлинных фотографий выбранного артикула и расцветки. На телефоне работает нативный горизонтальный свайп; на компьютере — кнопки, точки и клавиши ← / →. В подробной карточке доступна такая же галерея. Дополнительные фотографии подгружаются по мере просмотра. При ошибке загрузки фотография исключается; если недоступны все, показывается заглушка.

## Источники

- Nike: `selectedProduct.contentImages`, `colorDescription`, назначение из `sportTags` и `taxonomyLabels` публичной страницы выбранного SKU.
- Puma: `variations[].images`, `colorName` и категория из состояния публичной страницы. Выбирается только вариация с совпадающим артикулом и цветом.
- Reebok: `images`, опция Color и тематические теги из публичного товарного фида того же товара.

Сборщики сохраняют поля `image_urls`, `color`, `usage`; адаптеры преобразуют их в `Product.imageUrls`, `color`, `usage`. Эти данные входят в обычное обновление каталога дважды в день. URL ракурсов не конструируются и не угадываются.

Для уже опубликованных снимков дополнительные данные собраны в `data/catalog/product-media.json` с ключом по ID товара. Новые сведения из обычного снимка имеют приоритет. Дополнение не изменяет стоимость, наличие или время проверки товара.

Повторное заполнение дополнения:

```sh
node scripts/enrich-catalog-media.mjs --online
```

Nike использует сохранённые страницы `artifacts/nike-live/<SKU>.json`; Puma и Reebok — доступные публичные страницы/фид. Скрипт проверяет robots.txt, соблюдает задержку и прекращает запросы к источнику при ошибке доступа. Без `--online` обрабатываются только локальные данные Nike. После проверки результата закоммитьте JSON, чтобы он вошёл в сборку Vercel.

## Подборки и описания

Параметр каталога `collection`: `daily`, `running`, `training`, `monochrome` или пустое значение. Его можно комбинировать с остальными фильтрами. Назначение определяется по названию и категории магазина; неизвестное назначение не подменяется повседневным.

«Чёрные и белые» включает расцветки с чёрным/белым и нейтральными оттенками, без указанных ярких цветов. Для неизвестного обозначения цвета товар не включается в эту подборку.

Краткое русское описание использует подтверждённое назначение и обозначения Wide, Slip-on, Retro в названии. Материалы, технологии и свойства не выдумываются.
