# Таблица размеров STEPPE

Проверено 25 сентября 2026 года. Кнопка «Таблица размеров» находится над выбором размера в каждой карточке. В таблице только варианты из `product.sizes`; нажатие выбирает исходную строку размера, поэтому цена по размеру, корзина и WhatsApp продолжают работать без преобразования ключей вариантов.

## Источники

- [Puma: официальные таблицы US / EU / Length cm](https://au.puma.com/au/en/sizecharts/sizecharts.html), отдельные Men's shoes и Women's Shoes.
- [Reebok: официальные таблицы US / EU / CM](https://reebok.com.au/pages/size-guides), отдельные Men's Footwear и Women's Footwear. Это справочная региональная сетка, а не подтверждённая таблица каждого артикула американского каталога.
- [SuperStep Казахстан: региональное обозначение RU](https://superstep.kz/size-table/). RU ≈ EU − 1 используется только как явно приблизительный ориентир для взрослых. Это не утверждение о едином стандарте Казахстана.

## Ограничения

CM перенесён из колонки производителя. Он намеренно не называется длиной стопы или стельки: региональные таблицы брендов расходятся, а [американская таблица Reebok](https://www.reebok.com/pages/size-guides) отдельно публикует Heel-Toe Measurement в дюймах. Эти значения не смешиваются с CM.

US M и US W выбирают разные таблицы. Для унисекс Puma с явным EU показывается мужская таблица (US M). Голый US у унисекс не преобразуется: без M/W его система неизвестна. Размеры с шириной, диапазоны и другие неподдерживаемые записи сохраняются как есть; автоматически отбрасывать часть строки нельзя.

Детские размеры не преобразуются по взрослым таблицам. Для них показывается исходная маркировка и рекомендация уточнить сетку модели. Прочерк означает отсутствие подтверждённого соответствия; размер остаётся доступным для выбора.

Если появится официальная сетка конкретного артикула, она должна иметь приоритет над общим справочником. RU, EU, US и CM из справочника не записываются в заказ вместо исходного размера.

## Проверки

`npm test -- tests/size-guide.test.ts` — бренд, пол, пограничные/неоднозначные размеры, сохранение ключей.

`npx playwright test tests/e2e/size-guide.spec.ts` — выбор из таблицы, цена варианта, сохранение корзины, мобильный экран, клавиатура и доступность.
